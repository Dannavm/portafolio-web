# Portafolio web – Danna Vera

Mi portafolio personal: una página de una sola vista con mis habilidades, experiencia y proyectos. Está en español e inglés, con modo claro y oscuro.

## Características

- Cambio de idioma ES / EN, que se recuerda al recargar
- Modo claro y oscuro, con la preferencia guardada
- Diseño responsive, pensado también para celular
- Navegación con desplazamiento suave entre secciones
- Textos separados del diseño, en un solo archivo (`src/lib/content.ts`)

## Tecnologías

- Next.js (App Router)
- React y TypeScript
- Tailwind CSS

## Cómo correrlo

```bash
npm install
npm run dev
```

Luego abre http://localhost:3000 en el navegador.

## Estructura

```
src/
├── app/            Página principal, layout y estilos globales
├── components/     Navbar, Hero, Skills, Experience y Providers
└── lib/content.ts  Textos en español e inglés
```
